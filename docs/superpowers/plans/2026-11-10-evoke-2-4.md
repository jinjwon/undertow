# Evoke 2.4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a person choose Claude Code, Codex or both; preview PDF, media, HTML and Markdown inside the app with live reload; fix the theme defects found in the 2.3 check; update the docs and the GitHub About; release 2.4.0 for macOS and Windows.

**Architecture:** One loopback HTTP server in the main process (`desktop/serve.cjs`) serves files of the open projects under a per-run secret path. Every preview is an `<iframe>` on that server: Chromium's own viewers show PDF and media, HTML gets a reload script, Markdown is rendered on the server. The agent choice is one stored value read through three pure helpers.

**Tech Stack:** Electron 45, React 18, Vite 6, `node:http`, `node:fs.watch`, `marked` (new, the only new dependency), `node --test`.

**Spec:** the conversation of 2026-11-10 (no spec file). The decisions taken from it are written in this plan; where the plan says "decision", it was Claude's call, not the user's.

## Global Constraints

- Version `2.4.0` in `desktop/package.json`, `desktop/package-lock.json` (first two `"version"` lines) and `CHANGELOG.md`.
- Work on branch `feat/agents-preview`, from `main` at `bbb9f11` or later. One commit per task. PR, merge, delete the branch.
- Every new UI string exists in `en`, `ko` and `ja` in `desktop/src/i18n.ts` (a test enforces it).
- Every new control must be checked in both themes, TIDE (Persona 3 Reload look) and REBEL (Persona 5 look), by screenshot.
- The preview server binds `127.0.0.1` only, never `0.0.0.0`.
- The app still makes no network request of its own; a previewed page may load what it asks for.
- Do not commit `desktop/src/LayoutEdit 2.tsx`, `layout 2.ts`, `layout.test 2.ts` (Finder duplicates, untracked).
- QA rules: launch with `env -u ELECTRON_RUN_AS_NODE npx electron . --remote-debugging-port=9461 --user-data-dir=<scratchpad>/profile`; kill only that profile's processes; never quit `/Applications/Evoke.app`.
- Out of scope (decision): Word, Excel and PowerPoint preview; Codex session history, usage HUD and skills list; editing files on an ssh server.

## Review Focus

1. A preview URL with `..`, `%2e%2e`, a backslash, or a symlink that leaves the project must return 404 and no file content. (Task 2, Step 1)
2. A request with the wrong secret, or a `Host` header other than `127.0.0.1:<port>`, must return 403, so another web page on the machine cannot read project files. (Task 2, Step 1)
3. A person with Codex only and no `~/.claude.json`: the app starts, lists the projects Codex trusts, and never starts `claude`. (Task 1, Steps 1 and 6)
4. Changing the agent setting while sessions run: the disabled agent's terminals are killed, the visible tab moves to an enabled one, and nothing keeps running unseen. (Task 1, Step 6)
5. Markdown that contains `<script>`, and HTML without `</body>`: the script must not run, and the reload script must still be added. (Task 2, Step 1)

### Task 2: Preview server

**Files:**
- Create: `desktop/serve.cjs`, `desktop/serve.test.cjs`
- Modify: `desktop/package.json` (`dependencies`: `marked`; `build.files`: add `serve.cjs`; `test` script: add `serve.test.cjs`), `desktop/package-lock.json`

**Interfaces:**
- Produces, in `serve.cjs`:
  - `typeOf(name: string): string` — MIME type by extension; `application/octet-stream` when unknown. Must know: html, htm, css, js, mjs, json, svg, png, jpg, jpeg, gif, webp, ico, pdf, mp4, webm, mov, mp3, wav, ogg, woff, woff2, txt, md.
  - `inject(html: string, nonce: string, liveUrl: string): string` — adds `<script nonce="…">new EventSource("<liveUrl>").onmessage = () => location.reload()</script>` before the last `</body>`, or at the end when there is none.
  - `start(opts: { roots: () => string[]; guard: (file: string) => Promise<string>; markdown: (text: string) => string }): Promise<{ port: number; token: string; urlOf(file: string): string | null; changed(): void; close(): void }>`
- URL shape: `http://127.0.0.1:<port>/t/<token>/<root index>/<path with forward slashes, each part encodeURIComponent>`. `urlOf` returns `null` for a file outside every root. `changed()` tells every open page to reload. The live stream is `/t/<token>/__live`.

- [ ] **Step 3: Main process**

- Start the server lazily on the first `preview:url`: `roots: () => [...roots]`, `guard`, `markdown: text => marked.parse(text)`.
- `preview:url` (file): `await guard(file)`, return `urlOf(file)`; throw if `null`.
- `preview:open` (url): `shell.openExternal(url)` only when `url` starts with `` `http://127.0.0.1:${port}/t/${token}/` ``.
- Reload trigger: one `fs.watch(root, { recursive: true })` per root, started with that root's first preview; ignore events whose path has a `.git` or `node_modules` part; call `changed()` at most once per 150 ms. Close watchers and the server in `before-quit`.
- `win.webContents.on('will-frame-navigate', …)`: `preventDefault()` for a sub-frame URL that does not start with the preview origin.
- `index.html` CSP: add `frame-src http://127.0.0.1:*`.

- [ ] **Step 4: Renderer**

- `Tab` gets `web?: string` (the URL). Tab id for a preview of an editable file is `live:<path>`; a `direct` file uses its own path.
- `openFile`: when `previewKind(path) === 'direct'`, do not read the file as text; `web = await api.previewUrl(path)`.
- A `LIVE` chip at the right end of `.tabs`, shown when the active tab is a text tab with `previewKind === 'live'`; it opens or focuses `live:<path>`.
- A web tab draws `.web-view`: a bar with the URL as text, a reload button (remount the iframe with a new `key`) and an open-in-browser button (`api.previewOpen`), then `<iframe src={tab.web}>` with no `sandbox` attribute (Chromium refuses its PDF viewer in a sandboxed frame; the frame is another origin and has no preload).
- The focus-sync effect and the save path skip tabs with `web`.
- Tab label: `◉ ` before the name of a `live:` tab.

Strings: `live.open` "Live preview" / "라이브 미리보기" / "ライブプレビュー"; `live.reload` "Reload" / "새로 고침" / "再読み込み"; `live.browser` "Open in the browser" / "브라우저에서 열기" / "ブラウザで開く".
